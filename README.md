# 🚗 Used Car Price Prediction

A Deep Learning project that predicts used car prices using a Neural Network built with PyTorch.

## 📌 Overview

This project was created as part of my hands-on Deep Learning learning journey. The goal is to understand how a Neural Network can be used for a regression problem such as used car price prediction.

The project includes:

- Data preprocessing
- Feature engineering
- Feature normalization
- Neural Network training
- Loss visualization
- Model saving and loading
- Price prediction
